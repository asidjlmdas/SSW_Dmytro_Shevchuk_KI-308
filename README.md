# VM Process Manager

Програмне забезпечення для керування процесами віртуальної машини на C++.

## Функції програми

1. Запуск нового процесу у віртуальній машині
2. Зупинка виконання процесу (примусова або коректна)
3. Призупинення та відновлення процесу
4. Перегляд списку всіх активних процесів VM
5. Моніторинг використання CPU та пам'яті процесом
6. Зміна пріоритету виконання процесу
7. Пошук процесу за іменем або PID
8. Завершення зависших процесів за таймаутом
9. Збереження логів подій процесів у файл
10. Відображення дерева батьківських і дочірніх процесів
