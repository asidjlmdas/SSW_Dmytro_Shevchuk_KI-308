Тема: Розробка програмного забезпечення для керування процесами віртуальної машини. Розробка програми, що дозволяє керувати процесами, що виконуються у віртуальній машині, та виконувати різні дії з їх управлінням.

Опис функціоналу програми:

Перегляд процесів (Process Explorer):
Відображення списку всіх активних процесів у віртуальній машині у зручному вигляді з можливістю швидкої навігації та оновлення даних.

Пошук процесів:
Можливість знаходити процеси за назвою або ідентифікатором (PID) у системі для швидкого доступу до потрібних задач.

Операції з процесами:
Підтримка основних операцій: запуск нових процесів, завершення (kill), призупинення та відновлення виконання процесів.

Інформація про процес:
Відображення детальної інформації про процес: PID, використання процесора (CPU), оперативної пам’яті (RAM), стан процесу та час виконання.

Сортування та фільтрація:
Можливість сортувати процеси за різними параметрами (назва, використання CPU, пам’яті) та фільтрувати список для зручності роботи.

Моніторинг ресурсів:
Відображення використання системних ресурсів процесами у реальному часі для аналізу навантаження системи.

Керування пріоритетами процесів:
Можливість змінювати пріоритет виконання процесів для оптимізації роботи системи.

Аналіз навантаження:
Визначення найбільш ресурсозатратних процесів для підвищення ефективності роботи віртуальної машини.

Журнал дій (Log):
Запис усіх дій користувача (запуск, завершення, зміна стану процесів) у спеціальний журнал для контролю та аналізу.
